# 🔔 업무포털 알리미 (나이스·에듀파인 윈도우 팝업 알림 에디션)

전국 교육청 업무포털, **나이스(NEIS)** 및 **K-에듀파인**의 미결/결재 대기 문서를 주기적으로 자동 확인하여, 새로운 문서가 도착했을 때 화면 우측 하단에 **선명한 윈도우 팝업 카드**로 즉시 알려주는 스마트 교무행정 알리미입니다.

---

## ✨ 핵심 기능

1. **🔔 윈도우 네이티브 팝업 알림**:
   - 새 결재 문서가 도착하면 화면 우측 하단에 알림 카드가 뜹니다.
   - 알림 카드의 **[🚀 나이스 접속]**, **[🚀 에듀파인 접속]** 버튼을 누르면 자동 로그인된 브라우저가 즉시 열립니다.

2. **🚀 제로 메모리 & 스텔스 모니터링**:
   - 모니터링 확인 시 화면 밖 투명 좌표에서 3초 만에 미결 문서를 읽어옵니다.
   - **확인 완료 즉시 브라우저 프로세스를 100% 완전 종료하여 메모리를 회수합니다. (대기 중 메모리 점유 0MB!)**
   - 30분 세션 만료나 튕김 현상 없이 언제나 100% 안정적으로 동작합니다.

3. **🔄 GitHub 연동 1초 포터블 자동 업데이트**:
   - 설치형 프로그램이 아니어도 단일 `.exe` 상태에서 최신 버전을 스스로 감지합니다.
   - 새 버전이 출시되면 **[업데이트]** 버튼 클릭 한 번으로 **다운로드 ➔ 1초 만에 최신 파일 교체 ➔ 자동 재실행**이 진행됩니다.

4. **🔐 강력한 로컬 암호화 보안**:
   - 공인인증서 비밀번호는 Fernet 대칭키 암호화 알고리즘으로 암호화되어 로컬 PC에만 안전하게 보관됩니다. (외부 유출 절대 불가)

---

## 💻 사용 방법

1. `업무포털알리미.exe` 파일을 실행합니다.
2. 소속 **교육청**을 선택하고, **공인인증서 암호**를 입력한 후 **[암호 저장]**을 누릅니다.
3. 원하는 **체크 주기(예: 30분, 5분 등)**를 설정합니다.
4. **[▶ 모니터링 시작]**을 누르면 백그라운드 모니터링이 가동됩니다.
5. 새 문서가 도착하면 팝업 알림을 통해 바로가기를 이용하세요!
